# Workspace collaboration

This directory contains stable guidance and templates for contributors working on SystemMate.

## Files

- `collaboration.md` — working agreements, handoff expectations, and review checks.
- `templates/task.md` — concise task brief for scoped work.
- `templates/handoff.md` — handoff format for work that continues in another session.
- `logs/README.md` — rules for optional local activity logs.
- `logs/activity-template.md` — template for a short, local activity record.

Only the guidance and templates are tracked. Personal notes, generated reports, and dated activity logs should remain untracked.
